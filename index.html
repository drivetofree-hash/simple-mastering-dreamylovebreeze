Stereo Width
Splits the signal into mid (center) and side (stereo difference) and scales the side amount. Below 100% narrows toward mono; above 100% widens the stereo image. Mono sources are unaffected since they have no side signal to begin with.

All processing happens in your browser. Your file is never sent to a server. MP3 encoding is powered by the LAME encoder (lamejs port, LGPL-3.0), bundled directly in this file — no external requests needed.
This is a real working technical prototype. The EQ, compressor, and limiter are genuinely processed with Web Audio API nodes, and the meters read real-time values. The signal analysis above is computed with actual DSP measurements (peak/RMS, band energy, stereo correlation) — not a trained ML model, so treat it as a rough guide rather than a professional loudness/mastering report.
